Shared reference patterns: persistent navigation, pale blue surface, rounded white panels, store links and a large
footer. Phone layouts stack their desktop sections and replace navigation with a menu. Busog instead uses the owner’s
updated tubik-inspired sage/charcoal visual language, task-specific color blocks and working demo links. Features, How
it works and a friendly 404 complete the requested breadth beyond the reference captures.
