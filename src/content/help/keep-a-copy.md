## Export your changes

Open You and choose Export JSON. The browser downloads the current mock diary, goals, weights, water and source credits.
The optional personal USDA key is excluded.

## Understand local storage

Edits are stored only in this browser when storage is allowed. Private browsing, storage limits and clearing site data
can remove them. Export provides a portable record; this concept has no cloud sync or import feature.

## Restore the starting point

Choose Reset demo data, then Restore fresh demo. This creates Mara’s deterministic mock history relative to the current
Manila day and resets the profile. Export first if you want to keep edits.
